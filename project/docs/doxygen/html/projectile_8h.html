Detailed Description

Enumeration Type Documentation

◆ ProjectileType

enum ProjectileType

Variante comportamental do projétil.

Enumerator
PROJ_NORMAL 

Trajectoria linear simples.

PROJ_PIERCING 

Atravessa varios inimigos ate max pierce.

PROJ_HOMING 

Segue alvo actualizado por projectileUpdateHomingTarget.

PROJ_SKY_FALL 

Queda do ceu sobre coordenada alvo.

PROJ_NEAR 

Alcance curto / area proxima (torre especifica).
